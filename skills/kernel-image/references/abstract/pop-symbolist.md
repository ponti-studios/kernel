# Pop-Symbolist Mode

Use this reference for pop-symbolist fine-art prompts (the default mode for
objects, symbols, surreal compositions, and conceptual ideas).

**Tagline:** Graphic emotion. Symbolic glamour. Luxury finish.

Every prompt transforms figures, objects, and scenes into emotionally charged, graphically reduced, luxury-finished images with iconic clarity.

## Style DNA

The following six principles are non-negotiable across every prompt:

| Principle | What it means |
|---|---|
| **Graphic reduction** | Strong contour, clear shape hierarchy, selective exaggeration, dramatic silhouette |
| **Luxury finish** | Lacquered, glossy, crisp-edged, enamel-like, fabricated |
| **Symbolic compression** | Every element carries metaphor, emotional coding, or conceptual tension |
| **Emotional legibility** | The psychological core is graspable even when the image is surreal |
| **Designed color** | High-contrast, intentionally limited, emotionally coded palette |
| **Iconic composition** | One dominant visual idea, readable from a distance |

This is not realism, casual illustration, or painterly self-expression. It is **designed image-making.**

## Prompt Structure

Every prompt defines five elements:

| Element | What to specify |
|---|---|
| **Subject** | Who or what is depicted |
| **Emotional idea** | The psychological core — one word from the emotional vocabulary below |
| **Visual mode** | Portrait / still life / scene / relief / surreal composition / poster |
| **Material & finish** | Lacquer / gloss / enamel / chrome / resin / halftone |
| **Color architecture** | Dominant palette (one neutral anchor + one dominant color + 1–2 sharp accents) |

### Master Prompt Skeleton

```
Create a [visual mode] in a unified high-gloss pop-symbolist art universe.
Subject: [subject].
Emotional idea: [emotional idea].

Render with controlled graphic reduction, strong black contours, clean halftone
or flat-color logic, and a polished luxury finish. Surface should feel lacquered,
enamel-like, and gallery-worthy.

Palette: [dominant colors], anchored with black and cream/ivory.

Keep it iconic, legible from a distance, psychologically charged.
Avoid: grunge, painterly looseness, muddy color, generic realism, visual clutter.
```

## Color Palette Reference

**Neutrals (always anchor):** lacquer black, ivory/cream, mirror silver, chrome, charcoal

**Signature saturates:** lipstick red, cherry red, cobalt blue, electric blue, icy blue, lemon yellow, orange flame, hot pink, pale pink, platinum blonde, silver-lilac, deep violet, emerald accent

**Mood tones:** midnight navy, noir plum, dusty rose, powder blue, bruised violet, pearl gray

**Color rule:** one neutral anchor + one dominant color family + 1–2 sharp accents. More than three breaks cohesion.

## Emotional Vocabulary

Pick one per prompt:

> vanity · seduction · secrecy · appetite · grief · performance · obsession · cool detachment · entrapment · self-invention · glamour · tension · collapse · betrayal · longing · worship · danger · nostalgia · rage · artificial joy · loneliness · ritual

## Subject Categories

- **Icon portraits** — single faces/busts with strong emotional charge
- **Full-body figures** — suspended, posed, falling, performing
- **Relationship paintings** — two or more figures in psychological arrangement
- **Symbolic objects** — mirrors, phones, roses, knives, cigarettes, crowns elevated to icon status
- **Scenes** — bedrooms, dressing rooms, pools, stages, diners as emotional machines
- **Surreal compositions** — impossible scale, floating objects, visual metaphors
- **Poster-like prints** — flat but highly designed

Objects are emotional actors, not passive props. A mirror = fracture/vanity/surveillance. A cigarette = ritual/damage/glamour. Environments amplify meaning — they never overwhelm it.

## Technical Constraints

### Surface & Texture
**Use:** lacquer, enamel, gloss, resin, chrome, glass, polished acrylic, Ben-Day dots, halftone fields, crisp reflective highlights, clean flat color

**Avoid:** grunge, paper distress, canvas tooth, expressionist brush marks, weathering, dirt, splatter

### Linework
Confident, crisp, bold, graphic. Varies in thickness but never accidental. No scribbly edges, sketch behavior, or unresolved outlines.

### Composition
- One dominant focal element (face / object / gesture / confrontation)
- Primary + secondary element + controlled negative space
- Bold, cinematic cropping that intensifies the idea — not centers it safely

## What to Avoid

Generic comic-book art · horror poster language · painterly neo-expressionism · fantasy illustration · street art / graffiti · anime · pure photorealism · shabby vintage nostalgia · messy surrealism · low-detail vector minimalism · uncoded realism

## Quality Check

Before outputting the prompt, verify it answers **yes** to at least 8 of these:

1. One dominant visual idea?
2. Reads immediately from far away?
3. Looks intentionally designed?
4. Color feels edited and powerful?
5. Finish feels expensive/polished?
6. Symbolism feels real rather than decorative?
7. Avoids muddy realism and painterly drift?
8. Could hang beside other works without looking alien?
9. Emotionally legible?
10. Feels authored, not assembled?
