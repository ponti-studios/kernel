# Environment: Soft Studio

Large soft key light, gentle fill, subtle rim light, diffused shadows. No
dramatic contrast or harsh lighting. This is the default environment for
`toy-3d-material.md` and clean-studio product photography, and can be
loaded alongside any material/mode when the user asks for a softer,
friendlier feel.

## Core Directives

- Large soft key light as the dominant source.
- Gentle fill light to lift shadows without eliminating them.
- Subtle rim light for edge separation from the background.
- Soft, diffused shadow edges — no hard-edged cast shadows.
- No dramatic contrast, no harsh directional lighting, no near-black voids.

## Negative Constraints

Avoid: single dramatic light source, near-black negative space, hard shadow
edges, high-contrast falloff.
