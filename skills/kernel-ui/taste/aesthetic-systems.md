# Aesthetic Systems

Use these system categories to select a layout direction. This is a lookup, not
permission to invent local tokens.

| System | Use when | Layout signal |
| --- | --- | --- |
| Editorial | Content hierarchy and reading are primary | Strong type scale, measured column, restrained chrome |
| Utility | Repeated operational work is primary | Dense rows, stable controls, compact feedback |
| Archive | Records, references, and traceability are primary | Metadata, provenance, deliberate indexing |
| Instrument | Live status or monitoring is primary | Persistent state, clear thresholds, progressive disclosure |
| Gallery | Visual comparison is primary | Large media, controlled captions, predictable browsing |

Choose one system, record why it fits the task, and implement it through the
shared token and component system.
