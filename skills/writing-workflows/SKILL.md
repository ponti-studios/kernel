# Writing Workflows

Choose the procedure matching the requested outcome below and read only its relevant resources. Paths within a procedure are relative to that procedure's folder. Run its scripts from that folder when a command assumes a working directory.

Current user instructions and repository conventions take precedence over defaults and historical project examples. Keep work proportional to the requested outcome. Reuse existing authorization; seek input only for a missing decision or permission. A procedure does not authorize publishing, spending, deployment or messages to others by itself.

All writing belongs here, including Ponti Studios scripts, social derivatives, podcast copy, and written scene development. Hand approved material to studio-workflows for recording, rendering and assembly.
