# Essay

> Invoke with: the essay goal and source material.

This workflow owns the approved-essay trunk. Run the stages in order and load only the stage needed next.

1. Intake and direction: [stage-intake.md](stage-intake.md), [stage-direction.md](stage-direction.md).
2. Draft, critique, edit, and approve: the corresponding `stage-*.md` reference.
3. Derive self-contained posts or video only after approval: [extract-posts.md](extract-posts.md), [video.md](video.md), and [video-production.md](video-production.md).

For a raw thought-to-camera script, use [write-video-script](../write-video-script/WORKFLOW.md).
