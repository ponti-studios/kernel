# Write Essay

> Invoke with: the essay goal and source material.

## Definition of done

- approval stage checks pass
- derivations are self-contained and traceable to the approved essay

This workflow owns the approved-essay trunk. Run the stages in order and load only the stage needed next.

1. Intake and direction: [stage-intake.md](references/stage-intake.md), [stage-direction.md](references/stage-direction.md).
2. Draft, critique, edit, and approve: the corresponding `references/stage-*.md` reference.
3. Derive self-contained posts or video only after approval: [extract-posts.md](references/extract-posts.md), [video.md](references/video.md), and [video-production.md](references/video-production.md).

For a raw thought-to-camera script, use [write-video-script](../write-video-script/WORKFLOW.md).
