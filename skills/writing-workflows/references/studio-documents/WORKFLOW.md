# Studio documents and communications

Use these references to write Ponti Studios artifacts. Apply current user and
project requirements first; historical schemas and organizational examples are
defaults for projects that use those conventions.

- [Documentation structure](documentation.md): choose the canonical home and document type.
- [Engineering document contracts](engineering-documentation-contract.md): architecture and implementation documents.
- [Product email](product-emails.md): product communication copy.
- [Marketing](marketing.md): positioning and marketing artifacts.
- [Idea validation and PRD](idea-validation-prd-studio.md): validation brief and requirements.

Project lifecycle and operational changes use studio-workflows. Writing an artifact
does not authorize sending an email, posting marketing copy or changing lifecycle state.
