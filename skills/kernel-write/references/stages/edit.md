# Stage 4 — Edit

Fifth stage. Apply the critique findings — nothing else.

## Action

1. Use only: the draft, the critique findings, and the Stage 1 direction.
2. Fix every finding. If a finding is rejected, say why.
3. Do not introduce new claims, metaphors, or direction.

## Gate

- Every finding addressed (fixed or explicitly rejected with reason).
- The revised essay still passes the draft contract (length, no headers, rhythm, metaphor) and the style contract.
- Hand to Stage 5.

## Output

Return the revised essay in the same format as Stage 2 (title + body, no
headers, no fences). If a finding is rejected, list it under a trailing
`## Rejected Findings` section with the reason.
