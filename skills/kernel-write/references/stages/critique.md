# Stage 3 — Critique

Fourth stage. Review the draft against the style contract — never against taste.

## How To Critique

1. Read the draft against every rule below.
2. Classify findings: **holds** or **fails**.
3. Every fail must cite the rule it violates. If a fail can't cite a rule, it's taste — drop it.
4. Output findings only. Do not rewrite the essay in this stage.

## The Style Contract

### The Deal

Every essay makes exactly one claim. It builds that claim around a single metaphor. It is 300–800 words. It has deliberately uneven paragraph pacing. It does not explain itself. It ends on a strike.

### What It Does

**Opens cold.** No context. No background. No "In recent years..." The first sentence is already in the argument.

> ✓ You think you are talking to intelligence. You are not.

**Builds around one metaphor.** The metaphor IS the argument. Introduced by paragraph 2, carries the whole piece.

> ✓ This is the Stradivarius problem. A perfect violin makes zero sound until a musician picks it up and plays.

**Uses direct address.** Talks TO the reader. Not about them.

> ✓ You think you're watching intelligence. You're watching a text-prediction machine.
> ✗ One might observe that what appears to be intelligence is, in fact, text prediction.

**Varies paragraph length deliberately.** A one-sentence paragraph. Then four. Then one. Then six. The eye never settles.

> ✓ It isn't.
>
> The entire debate about whether AI is "really intelligent" is a distraction. Humans don't even understand how we ourselves think. We are flawed improvisational creatures. Demanding that machines replicate that is a weird goal.
>
> That is the problem.

**Ends on a strike.** Not a summary. Not a call to action. A sentence that lands and stops.

> ✓ The instrument is built. We need artists to play it.

**Uses fragments.** A fragment that completes a thought is better than a full sentence that adds nothing.

> ✓ Not because commands are cool. Because commands imply intent plus action.

### What It Never Does

- **Opens with context.** ✗ "The field of artificial intelligence has seen remarkable progress in recent years..."
- **Uses academic transitions.** ✗ Thus, it follows that... / Therefore, we must consider... / However, it is important to note... / Furthermore, the evidence suggests...
- **Uses "we" to create false consensus.** ✗ We often find ourselves... / We tend to believe that... / As a society, we...
- **Explains the metaphor.** ✗ "In other words, what I mean by the Stradivarius problem is..." (The reader got it. Trust them.)
- **Uses italics or bold for emphasis.** ✗ This is *really* important. If the sentence needs typography to land, the sentence isn't strong enough.
- **Ends with a question.** ✗ So what will you do about it? (Questions open. Strikes close.)
- **Cites statistics or studies.** ✗ According to a 2023 McKinsey report... (This is an argument from observation, not a report.)
- **Uses hedge words.** ✗ Arguably / Interestingly / Notably / Perhaps / Some might say / It could be argued
- **Uses exclamation points or emoji.** ✗ This changes everything! / The future is here 🚀
- **Has a "key takeaways" section.** The essay IS the takeaway.
- **Has uniform paragraph lengths.** If every paragraph is 3-4 sentences, it reads like AI.

## The Litmus Test

Read the essay aloud silently. Ask:

1. Does the first sentence make me pause or argue?
2. Can I see the metaphor? Does it carry the whole piece?
3. Are paragraph lengths visibly different from each other?
4. Did I use "thus," "therefore," "however," "furthermore" anywhere?
5. Does the last line land — or does it explain?
6. Would I know this wasn't written by ChatGPT?

## Gate

- Every finding cites a rule from this contract.
- The litmus test passes.
- Findings handed to Stage 4.

## Findings Format

Return findings in this exact structure. Each finding line must name the rule it
cites in brackets, using the rule anchors below:

```
## Findings

- [opens cold] <what violates the rule>
- [academic transitions] <what violates the rule>
```

Rule anchors: `opens cold`, `one metaphor`, `direct address`, `paragraph
length`, `strike`, `fragments`, `academic transitions`, `false consensus`,
`explains the metaphor`, `emphasis`, `ends with a question`, `statistics`,
`hedge words`, `exclamation`, `key takeaways`, `uniform paragraphs`.

A finding that cannot name a rule is taste — drop it.
