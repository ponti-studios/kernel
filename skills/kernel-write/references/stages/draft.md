# Stage 2 — Draft

Third stage. Write the essay first pass.

## Essay Contract

- **Length:** 300–800 words. Target 500. 900 is a failure. If it's 400 and lands hard, stop.
- **No section headers.** Not `### Section Title`. Not `**Bold Topic:**`. Nothing that breaks the flow into labeled sections. The structure must be invisible.
- **Paragraph rhythm:** at least two single-sentence paragraphs (landings — sharpest claims isolated in white space). No two adjacent paragraphs the same length. Count sentences before writing; vary deliberately — sequence like 2, 5, 1, 4, 1, 6, 3, 1, NOT 3, 3, 3, 4, 4, 3.
- **Architecture (invisible to the reader):**
  1. **Strike (1 para)** — drop the contradiction in the first sentence. Introduce the metaphor.
  2. **Setup (2–4 paras)** — what everyone gets wrong. How the metaphor reveals the truth.
  3. **Deepening (2–3 paras)** — push the metaphor further.
  4. **Obstacle (1 para)** — why isn't this obvious? The most honest paragraph.
  5. **Exit (1–2 sentences)** — not a conclusion. A strike. End on the metaphor.

## Output Format

```
# Title

[Essay body — no headers, just prose]
```

## Gate

- 300–800 words. No headers. Paragraph rhythm varied. Metaphor carried to the end.
- Hand to Stage 3 — do not self-approve.
