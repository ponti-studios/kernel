# Stage 1 — Direction

Second stage. Lock the essay's spine before a word is written.

## Action

1. Lock the **claim** — exactly one claim the essay makes.
2. Lock the **metaphor** — one concrete metaphor that becomes the structural spine:
   - Introduced by paragraph 2.
   - Carries every paragraph — each one relates back to it.
   - Concrete (violin, warehouse, engine) — never abstract ("paradigm").
   - Never explained directly; the reader gets it.
3. Confirm audience and intent.

## Gate

- One claim. One concrete metaphor.
- Explicit user instruction overrides inference.

## Output

Return the direction in this exact structure:

```
# Direction

**Claim:** <one claim, one sentence>
**Metaphor:** <one concrete metaphor — violin, warehouse, engine — not "paradigm">
**Audience & intent:** <who it's for, why now>
```
