# Plan to Tasks

> Invoke with: the plan, spec, or PRD to convert.

## When to use

- converting a plan, specification, or PRD into actionable task files
- decomposing work with dependency awareness

## Outputs

- independently actionable task files with acceptance criteria and dependencies

## Definition of done

- each task has explicit acceptance criteria, dependencies, and test notes
- granularity is independently executable

Read `references/original-prompt.md` before creating task files. Keep acceptance criteria, dependencies, testing, and task granularity explicit.
